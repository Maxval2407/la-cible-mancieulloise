# La Cible Mancielloise

Site officiel de La Cible Mancielloise.

## Principe de maintenance
Le dépôt GitHub est la source de vérité et conserve l'historique des modifications. Le site est conçu pour être mis à jour depuis ChatGPT sans manipulation de code par les responsables du club.

## Contenu
- Accueil et présentation du club
- Actualités
- Calendrier des challenges et compétitions
- Résultats structurés : tireur, catégorie, classement, séries et total, avec podium automatique pour les 3 premiers
- Galerie
- Informations pratiques

Les coordonnées et résultats réels ne doivent être publiés qu'après validation. Les contenus temporaires sont explicitement identifiés.

## Données
Les contenus courants sont regroupés dans `data/content.js` afin de faciliter les mises à jour. Une évolution ultérieure pourra ajouter publication Facebook (texte + visuel/logo), API ou back-office sans casser l'historique.

## Publication
Compatible avec un hébergement statique gratuit (GitHub Pages, Render ou équivalent).
